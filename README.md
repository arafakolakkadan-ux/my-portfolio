# Arafa Kolakkadan — Portfolio Website

A premium, fast, and fully responsive single-page portfolio website for Arafa. Built with rich typography, smooth transitions, viewport animations, and custom design layouts.

## Live Preview
You can run a local development server to test interactions and layouts:
```bash
python3 -m http.server 8080
```
Then navigate to `http://localhost:8080/index.html` in your browser.

## Core Features
- **Hero Header**: Features an embedded auto-playing video with interactive audio mute/unmute buttons and a dynamic typewriter role display.
- **About Section**: Highlighting skills, background credentials, and visual photography frames using modern viewport scanning overlays.
- **Services section**: Grid showing key service capabilities:
  - Viral AI Content Creation
  - Fast Website Creation
  - Digital Marketing
  - Creative Branding
- **My Work Process**: Staggered step card milestones illustrating business goal alignment, strategy planning, creative assets design, and final optimization steps.
- **Conversion Focus**: Replaced generic form layouts with prominent Contact CTA cards (Apply Now / Free Consultation) linking directly to pre-filled WhatsApp chat links.
- **Footer Navigation**: Clean horizontal grid layout aligning brand tags, copy details, and social links (WhatsApp, Instagram, LinkedIn, Facebook, and Email).

## Technologies Used
- **Structure**: Semantic HTML5 markup
- **Styles**: Vanilla CSS3 layout grids, custom design tokens, and smooth hover glow animations
- **Interactions**: Native JavaScript IntersectionObserver scroll-spying and layout reveals
- **Icons**: Clean outline inline SVGs
- **Deployment**: Git version control configured to push to GitHub
